# B站收藏夹整理进度工作台

中文本地工作台，监控收藏夹离线整理、分类、核验与访问状态。

- **GitHub 只托管代码**，收藏清单及凭据始终在本机。
- 默认只读。任何网页刷新、定时轮询都不会访问 B站，也不会写入账号。
- 当前 HTTP 412 持久熔断时仍可查看已保存的分类快照。
- 实际同步成功数仅从已验证日志显示；不把规划数字当作已完成。
- 显示各收藏夹未完成页数、待复核数量与清晰的下一步。

## 运行

在此仓库执行 `npm start`，然后访问 http://127.0.0.1:4198

默认读取 `~/Documents/Bilibili-Favorites-Review`，可以设置 `BILIBILI_FAVORITES_DATA_DIR` 指向其他私有数据目录。服务只监听 `127.0.0.1`。

## 隐私与安全

- 不需要 GitHub Token、B站 Cookie 或任何服务端登录。
- 只读取事先保存的本地 JSON；无 B站网络请求。
- API 仅输出统计与有限脱敏概览，不输出私密清单和凭据。
- 不支持写操作，不提供绕过 HTTP 412 的开关。
- 不要将 `Bilibili-Favorites-Review` 复制到 GitHub 仓库。
