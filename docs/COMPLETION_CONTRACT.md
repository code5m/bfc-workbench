## 用户最终目标（永久记录）

> 必须把 B站账号所有可访问的收藏夹完整盘点、准确分类，尤其是把「默认收藏夹」的所有有效视频放进正确的主题收藏夹，核验成功后安全清理默认收藏关系；不可遗漏、不可造成视频丢失、不可留下无说明的待办。工作台、Skills 和 GitHub 只是手段，**最终以打开 B站账号看到实际整理结果为完成标准**。

必须区分：
- **本地分类**：只是建议，不能算 B站已同步。
- **复制到目标夹**：账号确实添加成功，但默认夹可能仍保留源收藏。
- **确认目标存在**：实时回读 B站目标夹并定位 BV 号，有证据才算。
- **完成默认夹清理**：在目标收藏已回读且保留证据后，解除默认夹中的原收藏关系；不得先删除、再复制。
- **最终完成**：覆盖全部账号收藏夹；所有有效视频分配到目标夹并核验；默认夹无未处理有效收藏；无法恢复、失效、用户要求保留的例外逐项列入报告；无意外丢失；B站端最终复核通过。

## 自动执行与安全边界

1. 持续在本机离线分析、去重、分类、生成审核清单，不依赖 B站网络访问。
2. 工作台轮询的只是本地 JSON，不是 B站接口；持续**展示**不代表后台持续进行账号写入。
3. 检测到平台正常、授权工具可用，并恢复读取后，按中断点谨慎恢复；HTTP 412 熔断未解除不得自动重试。
4. 先查目标、再复制、回读成功后才可考虑移出默认目录；移出/取消收藏涉及原始关系变更，需要明确权限和恢复准备。
5. 账号最终验收以实际回读为准，默认夹尚未读全时不可能 ALL_DONE。
6. 项目代码可以提交 GitHub，但视频清单、Cookie、密钥、真实 BV 关系与审核日志不入仓库。
