## 本轮新增

1. `lib/offline-acceptance.mjs`：聚合本地快照、唯一视频分类、失效、冲突、默认收藏夹专项进度、缺失目标目录与账号状态。
2. `scripts/audit-offline.mjs`：生成 `offline-acceptance-report.json`，只写在本地个人数据目录，不上传 GitHub。
3. `tests/offline-acceptance.test.mjs`：验证 412 下绝不会错误宣称完成；缺失快照必须标记未完成。
4. 持续复用 G1-G8，禁止因本地任务全部跑完就标记 B站真实同步完成。

## 接下来不允许遗漏的账号端功能

本轮没有接入任何未经授权的账号操作。以后需要经平台允许接入：统一账号访问适配器、请求预算及熔断、持久增量读取、目标实时去重、逐批复制和真实回读、安全移出默认夹、完整回滚审计、最终全量对账。所有环节均为 G1-G8 验收前置条件。
