# 自选多端交付状态

## 已提供

- PC 浏览器工作台：`http://127.0.0.1:4198/#topics`
- 统一后端：专题、章节、排序、笔记、分类、进度、备份、差异监测和失效研究接口。
- 微信小程序源码：`clients/wechat-miniprogram/`，可导入微信开发者工具；读取服务端前先建立所有者会话。

## 小程序运行前提

1. 将 `app.js` 的 `apiBase` 替换为可从微信访问的 HTTPS 后端域名。
2. 在微信公众平台配置 request 合法域名和 web-view 业务域名。
3. 后端必须提供登录会话和用户权限；当前本地开发服务的 `127.0.0.1` 仅用于 PC 验证，不能作为小程序生产域名。
4. B站页面在小程序 web-view 中的登录、播放和返回能力需在目标主体和域名配置下逐项验收。

Android、iOS 和鸿蒙客户端尚未声称完成构建或设备验证；它们应复用同一套后端契约和领域状态，分别补充平台适配与真实设备证据。
